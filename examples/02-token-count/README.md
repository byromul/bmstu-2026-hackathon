# Сравнение токенов русской и английской инструкций

Учебный пример ART-0033 к слайду 22. Это подсчёт текста локальным токенизатором, без вызова модели и API. Он относится к теории и не использует приложение второй части.

## Метод

В [count.py](count.py) сохранены две равнозначные инструкции: добавить импорт CSV, менять только модуль и тесты, не добавлять зависимости, обработать пустой файл, запустить проверки и показать результат. Подсчёт: `tiktoken==0.12.0`, `encoding_for_model('gpt-4o')`, фактически `o200k_base`, метод `encode_ordinary`. Рамка сообщения, служебные инструкции, история и ответы не включаются. Хеши текстов и результаты сохраняются в [result.json](result.json).

## Повторение

Из корня репозитория в отдельном виртуальном окружении Python:

```sh
python3 -m venv .venv-token-count
.venv-token-count/bin/python -m pip install tiktoken==0.12.0
.venv-token-count/bin/python examples/02-token-count/count.py
```

На Windows используйте `py -m venv .venv-token-count` и `.venv-token-count\Scripts\python.exe` вместо пути `bin/python`. Этот вариант Windows не запускался. Первый подсчёт скачивает словарь с официального адреса; с заполненным кэшем подсчёт работает без сети. Не добавляйте виртуальное окружение в Git. Сборка презентации использует уже сохранённые числа и не требует tiktoken.
