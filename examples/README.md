# Практические примеры

Здесь хранятся все примеры лекции: исходники, команды, инструкции, проверки и резервные материалы демонстраций. Примеры пока не добавлены.

## Организация

Для самостоятельного примера создавайте каталог `NN-short-name/`, например `01-agent-loop/`. Это соглашение о названии, а не существующий пример.

В `README.md` каждого примера описывайте:

1. Учебную задачу и ожидаемый результат.
2. ОС, оболочку, версии инструментов и предварительные навыки.
3. Установку зависимостей, настройку модели и доступа без реальных ключей.
4. Рабочую директорию и точную последовательность команд.
5. Задание для агента и действия лектора или студента.
6. Способ проверки результата и ожидаемый вывод.
7. Типичные ошибки, восстановление исходного состояния и резервный показ.
8. Дату проверки, окружение, результат и оставшиеся ограничения.

Сохранённый вывод, снимки демонстрации и готовый результат размещайте внутри соответствующего примера. Отмечайте, что это заранее подготовленные материалы. Проверяйте отсутствие секретов и персональных данных.

До фактического запуска указывайте статус «не проверено». Не рассчитывайте на дословное повторение ответа модели: проверяйте результат выполнения задачи.
