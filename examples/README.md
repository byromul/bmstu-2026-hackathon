# Практические примеры

Создан [01-task-id](01-task-id/README.md): короткий пример для каркаса практического блока о различии идентификатора задачи и позиции в списке. Код с намеренной ошибкой запущен и проверен; это ещё не приложение для 40-минутного демо. Проект и обязательные механизмы определены в [практической основе](../SPEC.md#практическая-основа); детали, которые ещё нужно выбрать, перечислены в [открытых вопросах](../SPEC.md#открытые-вопросы).

Для теории подготовлен [02-token-count](02-token-count/README.md): локальное сравнение одной пары равнозначных русской и английской инструкций, с текстами, методом и результатом. Основное приложение демонстрации при этом не разрабатывалось.

## При подготовке примера

Организация каталогов задана в [AGENTS.md](../AGENTS.md#редактирование-материалов). README каждого примера должен выполнять [требования воспроизводимости](../SPEC.md#воспроизводимость). Конфигурация, задания, skill, учебный AGENTS.md, результаты проверок и резервные состояния хранятся рядом с исходниками; полезные результаты регистрируются в [индексе](../ARTIFACTS.md).

Проверку permissions и хуков проводите по [требованиям демо](../SPEC.md#обязательные-элементы-демо), запрета `git push` — по [отдельному сценарию](../SPEC.md#хуки-и-запрет-git-push). Статус «проверено» ставьте только после фактического запуска в указанном окружении.

Учебные письма и другие короткие примеры для теории также размещаются здесь и не требуют доступа к реальным аккаунтам. В презентацию и сценарий включайте нужные фрагменты и ссылки на исходные материалы.
