# Инструкции учебного приложения

Эти правила действуют только в этом примере. Требования к функции находятся в SPEC.md, порядок работы — в PLAN.md.

- Используй Python и стандартную библиотеку приложения; изменения функции делай в tasks.py.
- ID задачи не является индексом списка. Не ослабляй существующие тесты, чтобы скрыть ошибку.
- Не меняй конфигурацию разрешений, защитный плагин и почтовый сервер ради выполнения задачи.
- Запуск приложения: `python app.py`. Тесты: `python -m unittest discover -s tests -v`.
- Полная локальная проверка: `python check.py`. Применяй skill review-change после изменения.
- Не читай личные файлы и секреты. Используй только учебные данные этого каталога.
- git push запрещён. Не обходи запрет другими командами или API.
- Письмо разрешено только после приёмки, просмотра адресата и текста и отдельного подтверждения. Получатель в этом демо — boss@example.test в локальном Mailpit.
- В отчёте различай фактический запуск, сверку документации и непроверенные предположения. Не называй письмо доставленным по одному черновику.
