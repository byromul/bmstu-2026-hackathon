# Спецификация учебного изменения

Цель: пользователь отмечает выбранную задачу выполненной в локальном Python-приложении. Единственная новая функция — завершение задачи; фильтры, вход пользователей и внешняя отправка из приложения не нужны.

## Приёмка

1. Нажатие кнопки у ID 1 меняет `done` только у ID 1; ID 2 остаётся прежним.
2. ID — идентификатор, а не позиция в списке. Проверить также ID 7 и 42.
3. Повторное завершение безопасно; задача остаётся выполненной.
4. Для неизвестного ID HTTP возвращает 404; сохранённые данные не меняются.
5. Состояние видно в браузере и сохраняется после перезапуска приложения.
6. Тесты проходят, Ruff не находит нарушений выбранных правил, Bandit проверяет исходники. Выполненные проверки и ограничения записаны в отчёте ревью; они не доказывают отсутствия всех ошибок.
7. Письмо о разработке отправляется отдельным MCP-инструментом после приёмки и подтверждения. Оно не является функцией списка задач.

Учебная среда слушает только 127.0.0.1 и работает с вымышленными данными. Это не production-приложение: нет многопользовательского доступа, авторизации и защиты для размещения в интернете.
