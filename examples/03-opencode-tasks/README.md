# Практика OpenCode: завершение задачи по ID

Материалы находятся в подготовке. Приложение и проверки реализованы; учебный SMTP-приёмник Mailpit согласован пользователем. Спецификация — [SPEC.md](SPEC.md), план — [PLAN.md](PLAN.md).

Фактически проверены HTTP-поведение, сохранение состояния, MCP → SMTP → локальные входящие и повтор без дубликата: [отчёт](reports/integration.json). Внешняя доставка не выполнялась. Живой агентский прогон готовится отдельно.

Во время подготовки пользователь обновил OpenCode с 1.14.48 до 2.2.6. Текущая конфигурация и плагин переводятся на V2; не использовать промежуточные команды как окончательную инструкцию.
