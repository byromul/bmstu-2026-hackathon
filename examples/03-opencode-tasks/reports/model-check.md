Дата: 2026-11-08. Ключ прочитан из файла, указанного пользователем; значение и HTTP-заголовки не сохранялись.

## Прямой API

- Публичный маршрут OpenCode для актуальной бесплатной GLM: HTTP 429, FreeUsageLimitError. Модель из старого каталога MiniMax: Model is unavailable. Это не успешный запуск.
- GLM-4.7-Flash через официальный Z.ai API: два HTTP 429 с кодом 1305, временная перегрузка.
- GLM-4.5-Flash через тот же официальный API: HTTP 200, ответ «Готово.», 18 входных и 5 выходных токенов. По [официальному прайсу](https://docs.z.ai/guides/overview/pricing) модель бесплатная; универсальная квота аккаунта не установлена.

## OpenCode V2

Пользователь обновил установленный OpenCode до 2.2.6 во время подготовки. Конфигурация адаптирована к V2; проверочные сессии используют отдельные каталоги данных и standalone-сервер. Рабочий пользовательский сервис не останавливался и не перенастраивался.

GLM-4.5-Flash реально прочитала AGENTS.md, SPEC.md, PLAN.md, tasks.py и тесты, изменила complete_task, запускала тесты, Ruff и Bandit через shell и смотрела git diff. Плагин guard записал LOADED OpenCode 2.2.6. Применение skill review-change зафиксировано завершённым вызовом skill, создан review.md.

Первый вариант неправильно обрабатывал bool ID; тест обнаружил ошибку. Модель несколько раз пыталась повторить идентичную правку, затем дошла до зелёных тестов. Дополнительное задание ART-0045 уточнило строгую проверку типа и возврат объекта задачи; проверки повторены. Наличие зелёного отчёта не заменяет независимую оценку: независимая приёмка нашла неверную обработку неизвестного ID 0. Лектор добавил 0 в существующий тест, агент по ART-0046 убрал проверку положительности ID, повторил 13 тестов, Ruff и Bandit и обновил review.md. Прямая проверка функции дала KeyError без изменения данных; HTTP-интеграция вернула 404 для 0 и 999. Автоматический отчёт модели о полном соответствии нельзя считать окончательным решением лектора.

Рабочий результат лектора в корне примера и фактическая правка модели учитываются отдельно. Реальные журналы и diff сохраняются в reports после удаления возможных секретов. Полная 40-минутная репетиция не проводилась.

## Реальный контроль действий и письмо

[Вызовы инструментов](opencode-mail-guard.json) из отдельной модельной сессии фиксируют shell git status (успех), shell git push (ошибка DEMO_GUARD до исполнения), mail_prepare_report, mail_send_report и mail_list_inbox. В файл включены пользовательские тексты и результаты инструментов; служебная авторизация не включена.

[Нативный запрос отправки](send-approval.json) появился после просмотра черновика и отдельного задания на отправку. Подготовительный клиент разрешил **once**, только конкретный запрос. Это не автоматическое разрешение всех будущих действий. Пользователь ранее одобрил локальный Mailpit; внешняя доставка не выполнялась.

[Получение и повтор](model-mail.json): новое модельное письмо найдено во входящих. Там также было одно более раннее письмо SDK, поэтому общее количество 2 не является дублем одного черновика. Последующий повтор того же draft_id клиентом официального SDK вернул already_received_locally; число писем осталось 2. Отдельный [интеграционный тест без модели](integration.json) также подтвердил черновик без отправки, одну доставку и повтор без дубля.

[Эффекты разрешений](permissions.json) проверены через реальный permission.create без исполнения проверочных команд; [ограничение edit](final-config-permissions.json) проверено для финальной конфигурации после загрузки локации. Холодный запрос может прийти раньше готовности проекта. Первоначальный пустой mcp list не считается успехом; в постоянном учебном сервере mail перешёл в connected, три инструмента реально выполнены моделью.

Исходные JSONL сохраняют одну продолжаемую сессию с несколькими заданиями; пересекающиеся потоки CLI не являются независимыми успешными попытками. [Diff](agent-change.patch) включает правку функции моделью и добавленный лектором случай 0 в тесте. [Отчёт модели](agent-review.md) сохранён как получен; его широкие выводы о безопасности скорректированы в [независимом ревью](../review.md).
