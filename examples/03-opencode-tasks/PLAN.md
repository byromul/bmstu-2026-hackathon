# План изменения

1. Прочитать SPEC.md, AGENTS.md, tasks.py и tests/test_tasks.py.
2. Уточнить поведение неизвестного и уже завершённого ID по спецификации.
3. Реализовать complete_task без индексации списка по ID и без новых зависимостей.
4. Запустить тесты; отдельно проверить браузер и сохранение состояния.
5. Применить review-change; прочитать diff и записать фактические команды и ограничения.
6. Подготовить черновик письма; после просмотра и подтверждения вызвать почтовый MCP.
7. Проверить входящие Mailpit и отсутствие дубля; сохранить итоговый отчёт.
