# Короткий учебный skill редактирования

ART-0074. Иллюстрация к слайду «Пример скилла», не установленный навык лектора. [SKILL.md](SKILL.md) показывает условие применения, шаги, ограничения и формат результата. Основа нескольких правил — локальный humanizer-ru (MIT); это сокращённый учебный пример, а не полная копия его процедуры.

Для самостоятельной пробы в OpenCode скопируйте SKILL.md в `.opencode/skills/readable-ru/SKILL.md` своего учебного проекта. Попросите убрать воду из короткого русского текста. Проверьте, что числа, имена и смысл сохранились, а нейтральный текст не переписан без причины. Числа, которых не было во входе, добавлять нельзя. Проверка не определяет, написан ли текст человеком или моделью.
