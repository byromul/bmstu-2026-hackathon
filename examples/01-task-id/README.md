# ID задачи и индекс списка

Самостоятельный учебный пример для слайда 02. Код намеренно ошибочен: используется идентификатор задачи как позиция в списке. Это иллюстрация для теории, не реализация приложения демонстрационного блока.

## Запуск

Из корня репозитория, Python 3.10 или новее, сторонние зависимости не нужны:

```sh
python3 examples/01-task-id/example.py
```

На Windows при установленном Python Launcher эквивалентная команда:

```powershell
py -3 examples/01-task-id/example.py
```

Ожидаемый вывод:

```text
ID 1: не выполнена
ID 2: выполнена
```

Вызов `complete_task(tasks, 1)` должен был изменить первую задачу, но меняет вторую. Встроенная проверка подтверждает воспроизводимость показанной ошибки; её успех не означает правильность функции.

## Проверка
