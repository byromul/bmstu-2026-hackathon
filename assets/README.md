# Визуальные материалы

Здесь хранятся иллюстрации и схемы для презентации. Визуальные материалы пока не добавлены. Материалы конкретных практических демонстраций храните вместе с примером в `examples/`.

- Используйте понятные имена: `agent-loop.svg`, `assistant-agent-comparison.png`.
- Подключайте файлы относительными ссылками из `slides.md`.
- Сохраняйте редактируемые исходники схем, когда они доступны.
- Проверяйте читаемость подписей и контраст в средстве показа.
- Для сторонних материалов фиксируйте источник и условия использования в `sources/README.md`.
- Удаляйте ключи, персональные данные и другие секреты со скриншотов.

## Порядок генерации изображений

1. Выделите следующий свободный ID в [индексе артефактов](../ARTIFACTS.md), например `ART-0005`. Добавьте запись со статусом «подготовка»; до создания результата укажите планируемое имя файла без ссылки.
2. Составьте эффективный промпт: учебная цель, объекты и связи, композиция, стиль, текст на изображении, соотношение сторон, фон и ограничения. Сохраните точный текст в `prompts/ART-0005-short-name-v01.md` **до запуска** и добавьте ссылку на него в индекс. Требования к записи приведены в [prompts/README.md](../prompts/README.md).
3. Выполните сохранённый промпт. Зафиксируйте инструмент, модель и доступные параметры, фактическую дату запуска и использованные референсы. Если инструмент недоступен, оставьте статус «подготовка» и запишите причину.
4. Сохраните полученный файл в `assets/ART-0005-short-name-v01.png` (расширение должно соответствовать фактическому формату). Не ограничивайтесь временной ссылкой сервиса.
5. Проверьте результат и обновите индекс: ID, ссылка на промпт, название и ссылка на файл, описание, статус и связь с исходным вариантом. Укажите ограничения или дефекты, если они есть.
6. Для нового варианта используйте новый ID и отдельный файл. Сохраняйте точный промпт каждого запуска; неизменённый промпт можно использовать повторно по ссылке. Предыдущие полезные варианты не удаляйте и не перезаписывайте.

Приведённые имена — примеры соглашения; эти изображения ещё не созданы. Сгенерированные иллюстрации сохраняйте здесь; записи выполнения учебных демонстраций остаются в `examples/` и также регистрируются в общем индексе.
