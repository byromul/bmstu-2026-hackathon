# Диаграммы Excalidraw

Смысловые данные и пожелания автора находятся в `slides.md`. Шаблоны размещения — в `graph-template.js`. Excalidraw SDK создаёт редактируемую сцену и экспортирует SVG; модель генерации изображений не используется.

## Первая проба

[Открыть пробный слайд](preview.html) · [Превью PNG](preview.png) · [SVG](../ART-0018-agent-loop-v01.svg) · [Исходник Excalidraw](../ART-0018-agent-loop-v01.excalidraw).

Проба принята пользователем как визуальный образец. Системный шрифт выбран ради читаемости; характер рисованных линий сдержанный. Исходник можно открыть в Excalidraw и редактировать. При повторной генерации ручные изменения исходника будут заменены данными и геометрией шаблона — сначала перенесите полезные изменения в шаблон либо сохраните отдельную версию с новым ID.

## Локальный инструмент

`export-entry.js` использует официальный `@excalidraw/excalidraw` 0.18.1. Его зависимости и версии зафиксированы в `package-lock.json`. Готовая сборка `vendor/export-bundle.js` сохранена локально; при обычной отрисовке npm и сеть не нужны. Комментарии о лицензиях включены в конец сборки. `node_modules` не входит в Git.

Для отрисовки нужен Node.js и Google Chrome. Проверенное окружение: Node v26.9.0, Chrome 156.0.8078.80, macOS arm64. При нестандартном расположении браузера задайте `CHROME_BIN`. Windows и Linux пока не проверены.

При изменении JS-шаблона сначала пересоберите локальный SDK:

```sh
npm run bundle --prefix assets/excalidraw
```

Для этого нужны установленные зависимости. Их восстановление командой `npm ci --ignore-scripts --prefix assets/excalidraw` — отдельная подготовительная операция, которая требует сети при пустом кэше. Пересборка HTML из уже сохранённых SVG по-прежнему выполняется командой из корневого README без Node.js, npm и доступа к сети.

## Проверка пробы

`render-report.json` фиксирует реальный запуск SDK с отключённой сетью, `preview-report.json` — загрузку SVG в автономном HTML, размещение и горячую клавишу N. Все пять узлов и пять связей проверены визуально в кадре 1600 × 900. После первой проверки исправлено смещение центрированных подписей; ход работы записан в сохранённом задании ART-0018.
