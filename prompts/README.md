# Промпты и сведения о запусках

Здесь хранятся учебные промпты и промпты создания артефактов. Сохранение промпта само по себе не означает его выполнение. Текущие версии и результаты зарегистрированы в [ARTIFACTS.md](../ARTIFACTS.md).

## Текущий учебный промпт

[ART-0011: стартовый промпт, версия 02](ART-0011-agent-start-v02.md) — текущий черновик для завершения теоретического блока. Предыдущая версия связана из его карточки. Статус проверки и история запусков находятся в самом файле. Задания на детерминированную отрисовку схем Excalidraw зарегистрированы в индексе; они сохранены до соответствующих запусков.

## Формат записи

Используйте имя `ART-NNNN-short-name-vNN.md`. Для самостоятельного учебного промпта ID относится к нему самому; для промпта генерации — к планируемому результату в индексе.

Файл содержит ID, назначение, статус, точный текст отдельным блоком, входные материалы, известные параметры и историю запусков. Входные заполнители объясняйте; неизвестные настройки не выдумывайте. Для изображений описывайте содержание, композицию, стиль, формат и ограничения. Порядок генерации задан в [assets/README.md](../assets/README.md#порядок-генерации-изображений).

После запуска сохраняйте текст и входные материалы неизменными; сведения о фактическом выполнении дополняйте отдельно: дата, инструмент, модель, параметры, ID и ссылка на результат либо описание ошибки. Новая редакция получает отдельный файл и ID со ссылкой на предыдущую. Неизменённый промпт может использоваться в нескольких запусках.
