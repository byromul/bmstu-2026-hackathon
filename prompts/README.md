# Промпты и параметры генерации

Сохраняйте промпт до его выполнения. Используйте имя `ART-NNNN-short-name-vNN.md`, связанное с ID результата в [индексе артефактов](../ARTIFACTS.md). Выполненные промпты не исправляйте задним числом: для изменения создавайте отдельную версию.

Файл должен содержать:

- **ID результата и назначение:** какой материал создаётся и какую задачу решает.
- **Точный промпт:** полный текст, передаваемый инструменту, в отдельном блоке. Для изображения опишите цель, содержание, композицию, стиль, формат, текст и ограничения. Избегайте противоречивых указаний.
- **Входные материалы:** ссылки на сохранённые референсы, исходники и предыдущие варианты; при их отсутствии укажите это явно.
- **Параметры:** инструмент, модель, размер, фон и другие доступные настройки. Недоступные или неизвестные значения не выдумывайте.
- **Запуски:** после каждого выполнения добавляйте дату, ID результата, ссылку на сохранённый файл и итог проверки либо описание ошибки. Один неизменённый промпт может иметь несколько запусков.

Точный промпт и входные материалы после запуска сохраняйте неизменными; сведения о запуске дополняйте отдельно. Удаляйте секреты до сохранения. Полезные неиспользованные промпты также сохраняйте и помечайте как невыполненные.

Промпты генерации пока не созданы.
