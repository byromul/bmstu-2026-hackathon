# Изображения для редакции после пользовательской проверки

ID: ART-0060–0068. Статус: задание сохранено до получения изображений. Дата: 2026-11-08. Основание: пользователь попросил первый экран терминального агента, свой мем и горизонтальные ряды логотипов.

## Точный текст

```text
Добавить изображение терминального интерфейса OpenCode перед объяснением агентского цикла. Предпочесть опубликованный проектом реальный снимок начального экрана; указать происхождение и не выдавать за собственный запуск. Если снимок показывает рабочую сессию, не называть его первым экраном.
На следующем слайде использовать предоставленный assets/LET-ME-OUT-meme-3.jpg без изменения: юмор о выходе из терминального агента и Vim. Сохранить целое изображение, не обрезать подписи.
Для двух слайдов сравнения получить логотипы Anthropic, OpenAI, Kimi, OpenRouter, Ollama, Z.ai и DeepSeek с официальных сайтов или из официального репозитория. Использовать исходные пропорции и цвета, встроить локальные файлы в HTML, расположить горизонтально с одинаковым полем для знака и подписью. Не рисовать и не генерировать логотипы. Сохранить точные URL и хеши в реестре источников. Изображения служат обозначениями продуктов, не означают их одобрения лекции.
```

Инструменты: загрузка публичных файлов через curl, просмотр исходников, нативный HTML/CSS для размещения. Модель генерации изображений не используется. Исходник мема предоставил пользователь; его отдельная лицензия не установлена.

## Уточнение получения начального экрана

Опубликованный снимок OpenCode показывает уже рабочую сессию и для первого экрана не подходит. Для ART-0060 запускается установленный OpenCode в отдельном временном каталоге с изолированными XDG-каталогами. Задача модели не отправляется, ключи пользователя не читаются. Сохраняется реальный вывод терминала; ANSI-экран воспроизводится в изображении без изменения текста.

## Результат получения

ART-0060: начальный экран установленного OpenCode 2.2.6, получен из настоящего PTY 120 × 32. Отдельные XDG-каталоги и свободный порт исключают подключение к пользовательской сессии. Задача не отправлялась; временный сервер остановлен. [Код получения](../assets/capture-terminal.py), [текст экрана](../sources/ART-0060-terminal-screen.txt). ANSI обработан pyte 0.8.2, SVG отрисован Chrome в PNG 1728 × 1040. Это воспроизведение вывода терминала, а не фотография окна Terminal.

ART-0061: исходный JPEG пользователя без изменений. ART-0062/64/65/66/67: официальные значки с сайтов; ART-0068: ICO сайта DeepSeek преобразован в PNG системным sips без изменения изображения. ART-0063: официальный сайт OpenAI возвращал HTTP 403; использован знак OpenAI из каталога провайдеров OpenRouter, происхождение отмечено отдельно. Генерации логотипов не было. URL и хеши записаны в ART-0069.
