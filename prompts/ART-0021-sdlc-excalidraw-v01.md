# ART-0021 — Жизненный цикл разработки

- **Назначение:** схема для первых десяти слайдов.
- **Тип:** задание на детерминированную отрисовку Excalidraw SDK; модель генерации изображений не используется.
- **Вход:** смысловые данные `slides.md`, макет `assets/excalidraw/graph-template.js`.
- **Версия:** 01; оформление продолжает одобренный образец ART-0018.

## Точный текст

Создать схему «Жизненный цикл разработки» для светлой презентации 16:9. Использовать Excalidraw: спокойные рисованные контуры, системный шрифт, фон #fafaf7, тёмный текст, бирюзовый акцент #17615f. Без декоративных иконок, номеров и теней. Текст не пересекает стрелки; подписи читаемы на слайде. Сохранить SVG без внешних ресурсов и редактируемую сцену .excalidraw.

Шесть крупных узлов в два ряда; нижний ряд читается справа налево. Замкнуть цикл стрелками. Подписи полностью внутри узлов.

Ограничения: Выделить реализацию спокойным цветом; Не представлять схему обязательным последовательным процессом.
