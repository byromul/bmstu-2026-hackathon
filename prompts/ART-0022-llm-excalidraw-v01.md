# ART-0022 — Получение ответа языковой моделью

- **Назначение:** схема для первых десяти слайдов.
- **Тип:** задание на детерминированную отрисовку Excalidraw SDK; модель генерации изображений не используется.
- **Вход:** смысловые данные `slides.md`, макет `assets/excalidraw/graph-template.js`.
- **Версия:** 01; оформление продолжает одобренный образец ART-0018.

## Точный текст

Создать схему «Получение ответа языковой моделью» для светлой презентации 16:9. Использовать Excalidraw: спокойные рисованные контуры, системный шрифт, фон #fafaf7, тёмный текст, бирюзовый акцент #17615f. Без декоративных иконок, номеров и теней. Текст не пересекает стрелки; подписи читаемы на слайде. Сохранить SVG без внешних ресурсов и редактируемую сцену .excalidraw.

Два раздельных ряда: обучение сверху, генерация снизу. Нижняя обратная стрелка показывает повтор до завершения ответа. Крупные подписи.

Ограничения: Не рисовать обучение на каждом запросе; Не смешивать цикл токенов с агентским циклом инструментов.
