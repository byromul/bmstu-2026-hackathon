# Проверка доступа к GLM

- **ID:** ART-0043.
- **Назначение:** проверить доступ к бесплатной GLM-4.7-Flash по короткому запросу.
- **Входы:** ключ из указанного пользователем файла; значение не выводится и не сохраняется.
- **Параметры:** официальный Z.ai API, max_tokens 128, thinking disabled.
- **Статус:** выполнен; GLM-4.7-Flash возвращает перегрузку, GLM-4.5-Flash отвечает.

## Точный текст

```text
Ответь одним словом: готово.
```

2026-11-08: официальный Z.ai API, ключ из файла пользователя только в памяти. GLM-4.7-Flash: два ответа HTTP 429, код 1305 (temporary overloaded). Резервная бесплатная GLM-4.5-Flash, тот же текст и параметры: HTTP 200, ответ "Готово.", 18 входных и 5 выходных токенов. Ключ и HTTP-заголовки не сохранялись.
