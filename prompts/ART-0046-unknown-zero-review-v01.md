# Независимая проверка неизвестного ID

- **ID:** ART-0046.
- **Связи:** ART-0035 и ART-0045.
- **Назначение:** проверить границу спецификации, пропущенную исходными зелёными тестами и ревью модели.
- **Статус:** выполнено в OpenCode 2.2.6 с GLM-4.5-Flash.

## Точный текст

```text
Независимая приёмка нашла ещё один случай: неизвестный ID 0 тоже должен дать KeyError
и HTTP 404 без изменения данных. Сейчас условие task_id <= 0 вызывает ValueError,
который HTTP-обработчик не переводит в 404. В tests/test_tasks.py лектор добавил
0 к проверке неизвестного ID. Исправь только complete_task: строгая проверка типа
через type(task_id) is int, затем поиск существующего ID без требования положительности.
Верни найденный объект задачи, для любого отсутствующего целого ID дай KeyError.
Запусти python check.py. Обнови review.md, назвав пропуск предыдущего ревью и ограничения.
Не меняй тесты, app.py, настройки и почтовый сервер. Не читай секреты и не отправляй почту.
```
