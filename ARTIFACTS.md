# Индекс дополнительных артефактов

Здесь учитываются исследования, промпты, изображения и другие дополнительные результаты работы. Основные документы перечислены в [README.md](README.md); их и README каталогов в этот индекс не добавляйте. Текущие требования и состояние подготовки находятся в [SPEC.md](SPEC.md).

Каждый дополнительный артефакт получает уникальный ID вида `ART-NNNN`. Не используйте выданные ID повторно, даже после удаления записи. Следующий свободный номер — `ART-0051`; после его назначения обновите этот ориентир.

Для нового варианта результата используйте новый ID со ссылкой на исходный. Историю изменений рабочих файлов храните в Git; отдельные архивные копии в репозитории не создавайте. Самостоятельные полезные варианты промптов или результатов могут сохраняться отдельными файлами. Для незакоммиченных изменений история ещё не сохранена.
