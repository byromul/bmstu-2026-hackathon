# Индекс дополнительных артефактов

Здесь учитываются исследования, промпты, изображения и другие дополнительные результаты работы. Основные документы перечислены в [README.md](README.md); их и README каталогов в этот индекс не добавляйте. Текущие требования и состояние подготовки находятся в [SPEC.md](SPEC.md).

Каждый дополнительный артефакт получает уникальный ID вида `ART-NNNN`. Не используйте выданные ID повторно, даже после удаления записи. Следующий свободный номер — `ART-0012`; после его назначения обновите этот ориентир.

Для нового варианта результата используйте новый ID со ссылкой на исходный. Историю изменений рабочих файлов храните в Git; отдельные архивные копии в репозитории не создавайте. Самостоятельные полезные варианты промптов или результатов могут сохраняться отдельными файлами. Для незакоммиченных изменений история ещё не сохранена.

| ID | Промпт | Название файла и ссылка | Описание | Статус | Связи / версия |
| --- | --- | --- | --- | --- | --- |
| ART-0007 | Не применимо | [sources/agent-development-topic-map.md](sources/agent-development-topic-map.md) | Карта из 30 тем профессиональной разработки с агентами и первичные источники | Справочный обзор; не программа лекции | Текущий выбор тем — в SPEC.md |
| ART-0009 | [Точный текст](prompts/ART-0009-agent-start-v01.md#точный-текст) | [prompts/ART-0009-agent-start-v01.md](prompts/ART-0009-agent-start-v01.md) | Стартовый промпт, версия 01 | Заменённый черновик; не выполнялся | Предыдущий вариант ART-0011 |
| ART-0011 | [Точный текст](prompts/ART-0011-agent-start-v02.md#точный-текст) | [prompts/ART-0011-agent-start-v02.md](prompts/ART-0011-agent-start-v02.md) | Текущий стартовый промпт, версия 02 | Черновик; не выполнялся и не проверялся на модели | Заменяет ART-0009; учитывает запрет git push в демо |

Для запланированного результата указывайте статус «подготовка» и имя без ссылки. Добавляйте ссылку после сохранения файла. Отделяйте получение результата от проверки; для заменённого варианта указывайте текущий. Формат промптов описан в [prompts/README.md](prompts/README.md#формат-записи), порядок генерации изображений — в [assets/README.md](assets/README.md#порядок-генерации-изображений).
