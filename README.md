# Агентская разработка: от ассистента до агента

Материалы лекции для студентов 2–5 курсов: переход от общения с ассистентом к выполнению задач агентом на примере OpenCode и модели китайского разработчика с бесплатным доступом в пределах квот.

Сейчас подготовлен каркас проекта. Содержание лекции, модель и демонстрации ещё предстоит разработать.

Все решения и полезные результаты сохраняются в репозитории. Перед генерацией сначала сохраняется промпт; после выполнения результат регистрируется в индексе. Предыдущие полезные версии сохраняются со связями между ними.

## Порядок подготовки

1. Уточнить открытые вопросы в `SPEC.md`, прежде всего длительность, формат практики и ОС.
2. Проверить доступность модели и совместимость с OpenCode; записать источники.
3. Подготовить и воспроизвести сквозной пример в `examples/`.
4. Наполнить `slides.md` и `script.md`, добавить визуальные материалы.
5. Подготовить резервную демонстрацию и провести репетицию по критериям спеки.

## Работа с Markdown

Файлы можно читать и редактировать в редакторе с предпросмотром Markdown. Слайд и соответствующий раздел сценария используют одинаковый заголовок `## Слайд NN. Название`. Слайды разделяются строкой `---`.

Средство показа и экспорта пока не выбрано. Команды установки, сборки и проверки будут добавлены после выбора и проверки инструментов.
