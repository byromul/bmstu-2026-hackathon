## Просмотр и сборка

Из корня репозитория выполните:

```sh
python3 assets/package_materials.py
python3 build.py
python3 build.py --block 1 --output lecture-theory.html
python3 build.py --block 2 --output lecture-practice.html
```

Нужен Python 3.10 или новее. Сборка бесплатна: скрипт использует только стандартную библиотеку, не обращается к моделям или сети. Откройте [lecture.html](lecture.html) в Google Chrome. Установка пакетов и локальный сервер не нужны.

Управление: **← / →** — слайды, **Home / End** — первый и последний, **N** — сценарий текущего слайда. При движении мыши появляется панель с кнопкой полного экрана. Заметки видны в том же окне: перед показом аудитории закройте их клавишей N.

CSS, JavaScript и локальные изображения встраиваются в HTML; шрифты системные. Сам показ автономен. Внешние источники требуют сети только при переходе. В показе нет ссылок на внутренние материалы и скачивание комплекта. Каждый HTML можно переносить отдельно. Учебный ZIP сохраняется в репозитории; его состав задан в assets/package_materials.py, ключи и рабочие данные исключены.

Редактируйте `slides.md` и `script.md`, затем повторяйте сборку. Формат исходника и оформление описаны в [assets/README.md](assets/README.md#формат-слайдов). Текущий объём готовности — в [спеке](SPEC.md#критерии-готовности).

Проверки конвертора:

```sh
python3 -B assets/test_build.py
```

Проверка автономного показа и обновление [галереи превью](assets/preview/index.html):

```sh
node assets/verify-deck.mjs
```

Нужны Node.js и Chrome; подробности — в [assets/README.md](assets/README.md#обновление-превью). Проверены 48 слайдов и оба отдельных блока без сети; прошли 24 теста конвертора. Результаты — [ART-0079](sources/ART-0079-remove-grade-example.md). Сквозной запуск практического проекта описан в его README; репетиция 40 + 40 минут и Windows остаются непроверенными.
