# Агентская разработка: от ассистента до агента

Репозиторий подготовки студенческой лекции. Начните со [спецификации](SPEC.md): в ней находятся текущие требования, план и открытые вопросы. Дополнительные материалы доступны через [индекс артефактов](ARTIFACTS.md).

## Навигация

| Материал | Для чего открыть |
| --- | --- |
| [SPEC.md](SPEC.md) | Узнать, какую лекцию готовим и как принимаем результат |
| [AGENTS.md](AGENTS.md) | Прочитать правила работы над репозиторием |
| [slides.md](slides.md) | Работать с единым файлом презентации |
| [script.md](script.md) | Работать с единым сценарием лектора |
| [examples/](examples/README.md) | Найти демонстрационный проект и инструкции повторения |
| [assets/](assets/README.md) | Найти визуал и порядок его подготовки |
| [prompts/](prompts/README.md) | Найти промпты и сведения об их запусках |
| [sources/](sources/README.md) | Проверить источники и актуальность сведений |
| [DECISIONS.md](DECISIONS.md) | Понять основания решений и историю изменений |
| [ARTIFACTS.md](ARTIFACTS.md) | Найти дополнительные исследования, промпты и созданные результаты |

История сохранённых версий ведётся в Git. Незакоммиченные изменения в историю ещё не входят.

## Просмотр и сборка

Markdown-файлы можно читать в редакторе с предпросмотром. Средство показа и экспорта пока не выбрано; команд сборки и автоматической проверки ещё нет. После выбора инструментов проверенные команды будут размещены в этом разделе.
