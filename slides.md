## Материал для демо. Завершилась другая задача

Задание: отметить выполненной задачу с **ID 1**.

```python
tasks = [
    {"id": 1, "done": False},
    {"id": 2, "done": False},
]

def complete_task(tasks, task_id):
    tasks[task_id]["done"] = True

complete_task(tasks, 1)
```
