# Выбор движка диаграмм для лекции

Дата проверки документации: 2026-11-08. Статус: предложение для обсуждения; движок не выбран пользователем, не установлен и не запускался. Проверка PATH не обнаружила `d2`, `mmdc` или `dot`.

## Рекомендация

D2 для описания схем, ELK для компоновки, SVG для презентации. Это оценка пригодности к нашему проекту, а не результат сравнительного теста готовых диаграмм.

| Вариант | Возможности по документации | Оценка для лекции |
| --- | --- | --- |
| D2 + ELK | Группы объектов, темы, компоновка с прямоугольными маршрутами, экспорт SVG | Предпочтительный кандидат для процессов и архитектуры с общей темой оформления |
| Mermaid + ELK | Текстовые схемы, настройка компоновки; текущая документация описывает включение ELK в основную сборку | Рабочая альтернатива; стандартный внешний вид не означает ограничения только простейшими схемами |
| Graphviz | Автоматическая компоновка графов и экспорт SVG | Подходит для графов; для этой лекции предпочитаем более предметное описание схем D2 |

Первичные источники: [D2: компоновщики](https://d2lang.com/tour/layouts/), [D2: ELK](https://d2lang.com/tour/elk/), [D2: темы](https://d2lang.com/tour/themes/), [D2: экспорт](https://www.d2lang.com/tour/exports/), [Mermaid: компоновка](https://mermaid.ai/open-source/config/layouts.html), [Graphviz: SVG](https://graphviz.org/docs/outputs/svg/). Репозиторий D2 содержит [лицензию MPL-2.0](https://raw.githubusercontent.com/d2lang/d2/master/LICENSE.txt).

## Ограничения

ELK не обеспечивает ручную фиксацию всех координат: в D2 свойства `top` и `left` доступны только с TALA. У ELK возможны лишние изгибы связей и слабое соблюдение симметрии. Поэтому выбор D2 не гарантирует удачную композицию; нужны просмотр в кадре 16:9, крупные подписи и проверка стрелок. См. ограничения в источниках выше и [позиционирование D2](https://d2lang.com/tour/positions/).

## Предлагаемая интеграция

- Хранить смысловые данные и авторские указания в Markdown; исходники `.d2`, общую тему и SVG — в `assets/`.
- До отрисовки сохранять задание на диаграмму в `prompts/`. В ARTIFACTS.md связывать ID, задание, исходник и результат; не называть детерминированную отрисовку генерацией изображения моделью.
- Встраивать подготовленный SVG в HTML по ID. Обычная сборка `python3 build.py` использует сохранённые картинки без сети и вызовов моделей.
- Для изменения диаграмм понадобится локально установленная фиксированная версия D2. Автономную перегенерацию, кириллицу, шрифты и совместимость SVG с текущим конвертором ещё нужно проверить. Внешние ресурсы в схемах не использовать.

## Первые четыре схемы

1. SDLC: этапы и явный возврат обратной связи к требованиям.
2. Языковая модель: отдельно обучение; при использовании — контекст, токенизация, модель, следующий токен и продолжение генерации. Схема остаётся вводной, без архитектуры трансформера.
3. Agent loop: запрос модели, решение о вызове инструмента, контроль действия, результат, возврат в контекст; отдельный выход с итоговым ответом.
4. Harness: модель внутри организованной программной среды; контекст, управляющий цикл, инструменты и проверки прав. Схема состава отделена от схемы последовательности.

После согласования предлагается сначала проверить один образец agent loop и общий визуальный язык, затем использовать его для остальных схем. Это предложение порядка реализации, не выполненная работа.
