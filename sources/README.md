# Источники и проверка актуальности

Для обзорной карты тем собраны первичные источники. Модель, провайдер, тариф и конфигурация демонстрации с OpenCode ещё не проверены.

## Как фиксировать источник

Для каждого значимого утверждения добавляйте запись:

- **Тема:** какое утверждение или материал подтверждается.
- **Источник:** название и прямая ссылка на официальную документацию или первичный материал.
- **Дата проверки:** `YYYY-MM-DD`.
- **Подтверждённые сведения:** конкретные условия, версии и ограничения.
- **Где используется:** номер слайда, раздел сценария или путь к примеру.
- **Ограничения проверки:** что осталось неизвестным или не проверено на практике.

## Область проверки

Требования к сравнительной таблице заданы в [SPEC.md](../SPEC.md#модель-провайдер-и-vendor-lock-in), оставшиеся исследования — в [списке проверок подготовки](../SPEC.md#проверки-при-подготовке). Для стороннего визуала дополнительно указывайте источник и условия использования.

Отделяйте сведения из документации от результатов собственного запуска. Практические проверки команд записывайте в `README.md` соответствующего примера в `examples/`.

## Карта тем профессиональной разработки

- **Материал:** [Карта из 30 тем](agent-development-topic-map.md), ART-0007.
- **Дата проверки источников:** 2026-11-04.
- **Источники:** официальные руководства Anthropic по контексту, длительным задачам и evals; документация OpenCode по skills и плагинам; руководство MCP по безопасности; репозиторий GitHub Spec Kit. Прямые ссылки приведены рядом с соответствующими разделами карты.
- **Назначение:** обзорная карта; текущий выбор тем определяется [SPEC.md](../SPEC.md#учебные-результаты).
- **Ограничения:** проверено содержание документации; практических запусков и проверки тарифов в рамках обзора не было. Карта является авторской систематизацией, а не обязательным стандартом.

## Уточнения к содержанию теории

- **Дата проверки:** 2026-11-04.
- **Контекст и сжатие:** [Anthropic — Effective context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) описывает сжатие истории и внешние записи. Нельзя обещать, что вся видимая история всегда целиком находится в текущем контексте модели.
- **Блокировки Claude:** [официальная справка](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals) перечисляет нарушения правил и создание аккаунта из неподдерживаемой локации среди причин. Эта страница не устанавливает сравнительный тезис «банит агрессивнее остальных».
- **Доступ к OpenAI API:** [Supported countries and territories](https://developers.openai.com/api/docs/supported-countries) описывает географию API и риск блокировки доступа из неподдерживаемых территорий. Не переносить условия API автоматически на все способы доступа к Codex; продуктовую доступность уточнить отдельно.
- **Назначение:** уточнения для SPEC.md и будущего сценария.
- **Ограничения:** полная актуальная таблица моделей ещё не подготовлена; тарифы китайских провайдеров, оплата российскими картами и практическая работоспособность не проверены. Текущий стартовый промпт указан в [каталоге промптов](../prompts/README.md); практическая проверка ещё не выполнялась.
