## Проверенные основания

- [Anthropic: разделение harness, сессии и среды](https://www.anthropic.com/research/managed-agents), [Cloudflare: обязанности harness](https://developers.cloudflare.com/agents/harnesses/). Подтверждены инструменты, контекст/память, сохранение сообщений и цикл продолжения. Формулировка лекции обобщает обязанности инфраструктуры; конкретное разделение компонентов зависит от продукта. Это не утверждение о едином нормативном определении.
- [Ollama: облако](https://docs.ollama.com/cloud), [начало работы](https://docs.ollama.com/quickstart), [оплата](https://ollama.com/pricing). Есть облачный API и выбор локальной модели. Доступность из РФ и оплата конкретной картой не проверялись.
- [OpenCode: команды TUI](https://docs.dev.opencode.ai/docs/tui/#exit). Документация содержит /exit, а также /quit и /q. Выход из других продуктов не обобщается. Сам /exit при получении изображения не тестировался: временные процессы остановлены программно.
- [Anthropic: принципы доступа к инструментам](https://www-cdn.anthropic.com/43ec7e770925deabc3f0bc1dbf0133769fd03812.pdf). Наименьшие привилегии относятся к доступным инструментам. Progressive Tool Access в лекции — объяснение поэтапного открытия доступа, не название обязательного стандарта.
- Потеря данных при vendor lock-in изложена как условный риск отсутствия независимой копии/экспорта. Это сценарий для обсуждения, не результат испытания какого-либо поставщика.
